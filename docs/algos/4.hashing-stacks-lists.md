# Hashing, Stacks & Linked Lists

Three basic structures behind a huge share of interview questions.

| Structure | Superpower | Python |
|---|---|---|
| **Hash map / set** | lookup, insert, delete in $O(1)$ average | `dict`, `set`, `Counter`, `defaultdict` |
| **Stack** (LIFO) | the most recent unfinished thing | `list` with `append` / `pop` |
| **Queue** (FIFO) | process in arrival order | `collections.deque` |
| **Linked list** | $O(1)$ insert/delete when you hold the node | your own `ListNode` |

# Hash maps

A hash function maps a key to a bucket index; collisions are handled by chaining or probing. Average $O(1)$, worst case $O(n)$ if everything collides.

Use one when you catch yourself searching a list inside a loop: store what you have seen.

# Stacks and the monotonic stack

A **monotonic stack** keeps its elements in increasing (or decreasing) order. When a new element breaks the order, everything it pops has just found its **next greater (or smaller) element**. Each element is pushed and popped once: $O(n)$.

```text
next greater temperature: [73, 74, 75, 71, 69, 72, 76, 73]
i=3 71: stack [75, 71]
i=4 69: stack [75, 71, 69]
i=5 72: pops 69 (wait 1), 71 (wait 2) → stack [75, 72]
i=6 76: pops 72, 75 → stack [76]
```

# Linked lists

```text
head → [1] → [2] → [3] → None
```

Tricks to remember:

| Trick | Use |
|---|---|
| **dummy head** node | avoids special cases when the head changes |
| **fast / slow pointers** | middle of the list, cycle detection |
| **reverse in place** | `prev`, `curr`, `next` rewiring |

<details>
<summary>ListNode helper used below</summary>

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val, self.next = val, next

def build(values):
    dummy = ListNode()
    cur = dummy
    for v in values:
        cur.next = ListNode(v)
        cur = cur.next
    return dummy.next

def to_list(head):
    out = []
    while head:
        out.append(head.val)
        head = head.next
    return out

assert to_list(build([1, 2, 3])) == [1, 2, 3]
```

</details>

# Practice: hashing

## 1. Two Sum — Easy

Return indices of the two numbers (unsorted array) that add up to `target`.

```text
Input:  nums = [2, 7, 11, 15], target = 9
Output: [0, 1]
```

<details>
<summary>Hint</summary>

For each `x`, the partner you need is `target - x`. Keep a map `value → index` of what you've already seen.

</details>

<details>
<summary>Implementation — O(n)</summary>

```python
def two_sum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i
    return []

assert two_sum([2, 7, 11, 15], 9) == [0, 1]
assert two_sum([3, 2, 4], 6) == [1, 2]
assert two_sum([3, 3], 6) == [0, 1]
```

</details>

## 2. Group Anagrams — Medium

```text
Input:  ["eat", "tea", "tan", "ate", "nat", "bat"]
Output: [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
```

<details>
<summary>Hint</summary>

Anagrams share the same **sorted letters** (or the same 26-letter count). Use that as the dict key.

</details>

<details>
<summary>Implementation — O(n · k log k)</summary>

```python
from collections import defaultdict

def group_anagrams(words):
    groups = defaultdict(list)
    for w in words:
        groups["".join(sorted(w))].append(w)
    return list(groups.values())

assert group_anagrams(["eat", "tea", "tan", "ate", "nat", "bat"]) == [
    ["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
```

</details>

## 3. Longest Consecutive Sequence — Medium

Length of the longest run of consecutive integers, in $O(n)$ (no sorting).

```text
Input:  [100, 4, 200, 1, 3, 2]
Output: 4          (1, 2, 3, 4)
```

<details>
<summary>Hint</summary>

Put everything in a set. Only start counting from numbers that begin a run (`x - 1` not in the set), then walk `x + 1, x + 2, ...`. Each number is visited at most twice.

</details>

<details>
<summary>Implementation — O(n)</summary>

```python
def longest_consecutive(nums):
    s = set(nums)
    best = 0
    for x in s:
        if x - 1 not in s:                # x starts a run
            length = 1
            while x + length in s:
                length += 1
            best = max(best, length)
    return best

assert longest_consecutive([100, 4, 200, 1, 3, 2]) == 4
assert longest_consecutive([0, 3, 7, 2, 5, 8, 4, 6, 0, 1]) == 9
assert longest_consecutive([]) == 0
```

</details>

# Practice: stacks

## 4. Valid Parentheses — Easy

```text
Input:  "([]{})"   → True
Input:  "(]"       → False
```

<details>
<summary>Hint</summary>

Push openings; on a closing bracket, the top of the stack must be its matching opening. The stack must be empty at the end.

</details>

<details>
<summary>Implementation — O(n)</summary>

```python
def is_valid(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False
        else:
            stack.append(ch)
    return not stack

assert is_valid("([]{})")
assert not is_valid("(]")
assert not is_valid("((")
assert is_valid("")
```

</details>

## 5. Daily Temperatures — Medium

For each day, how many days until a warmer temperature (0 if never)?

```text
Input:  [73, 74, 75, 71, 69, 72, 76, 73]
Output: [1, 1, 4, 2, 1, 1, 0, 0]
```

<details>
<summary>Hint</summary>

Monotonic **decreasing** stack of indices still waiting for a warmer day. A warmer day pops and answers all the colder ones.

</details>

<details>
<summary>Implementation — O(n)</summary>

```python
def daily_temperatures(temps):
    answer = [0] * len(temps)
    stack = []                                # indices, temps decreasing
    for i, t in enumerate(temps):
        while stack and temps[stack[-1]] < t:
            j = stack.pop()
            answer[j] = i - j
        stack.append(i)
    return answer

assert daily_temperatures([73, 74, 75, 71, 69, 72, 76, 73]) == [1, 1, 4, 2, 1, 1, 0, 0]
assert daily_temperatures([30, 60, 90]) == [1, 1, 0]
```

</details>

## 6. Min Stack — Medium

Design a stack with `push`, `pop`, `top` and `get_min`, all in $O(1)$.

<details>
<summary>Hint</summary>

Store pairs `(value, min so far)`. The minimum at any moment is in the top pair.

</details>

<details>
<summary>Implementation — O(1) per operation</summary>

```python
class MinStack:
    def __init__(self):
        self.items = []                       # (value, current min)

    def push(self, x):
        current_min = min(x, self.items[-1][1]) if self.items else x
        self.items.append((x, current_min))

    def pop(self):
        self.items.pop()

    def top(self):
        return self.items[-1][0]

    def get_min(self):
        return self.items[-1][1]

s = MinStack()
s.push(-2); s.push(0); s.push(-3)
assert s.get_min() == -3
s.pop()
assert s.top() == 0 and s.get_min() == -2
```

</details>

# Practice: linked lists

## 7. Reverse a Linked List — Easy

```text
Input:  1 → 2 → 3 → 4 → 5
Output: 5 → 4 → 3 → 2 → 1
```

<details>
<summary>Hint</summary>

Walk the list keeping `prev`. For each node: remember `next`, point the node back to `prev`, advance.

</details>

<details>
<summary>Implementation — O(n) time, O(1) space</summary>

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val, self.next = val, next

def build(values):
    head = None
    for v in reversed(values):
        head = ListNode(v, head)
    return head

def to_list(head):
    out = []
    while head:
        out.append(head.val); head = head.next
    return out

def reverse_list(head):
    prev = None
    while head:
        nxt = head.next
        head.next = prev
        prev, head = head, nxt
    return prev

assert to_list(reverse_list(build([1, 2, 3, 4, 5]))) == [5, 4, 3, 2, 1]
assert reverse_list(None) is None
```

</details>

## 8. Linked List Cycle (Floyd) — Easy

Does the list contain a cycle? Use $O(1)$ memory.

<details>
<summary>Hint</summary>

Tortoise and hare: `slow` moves 1 step, `fast` 2 steps. If there is a cycle, `fast` laps `slow` and they meet; otherwise `fast` reaches `None`.

</details>

<details>
<summary>Implementation — O(n) time, O(1) space</summary>

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val, self.next = val, next

def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True
    return False

a, b, c = ListNode(1), ListNode(2), ListNode(3)
a.next, b.next = b, c
assert not has_cycle(a)
c.next = b                     # 3 points back to 2
assert has_cycle(a)
```

</details>

## 9. Merge Two Sorted Lists — Easy

<details>
<summary>Hint</summary>

Dummy head + tail pointer. Attach the smaller of the two current nodes each step, then attach whatever is left.

</details>

<details>
<summary>Implementation — O(n + m)</summary>

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val, self.next = val, next

def build(values):
    head = None
    for v in reversed(values):
        head = ListNode(v, head)
    return head

def to_list(head):
    out = []
    while head:
        out.append(head.val); head = head.next
    return out

def merge_two_lists(a, b):
    dummy = tail = ListNode()
    while a and b:
        if a.val <= b.val:
            tail.next, a = a, a.next
        else:
            tail.next, b = b, b.next
        tail = tail.next
    tail.next = a or b
    return dummy.next

assert to_list(merge_two_lists(build([1, 2, 4]), build([1, 3, 4]))) == [1, 1, 2, 3, 4, 4]
assert to_list(merge_two_lists(None, build([0]))) == [0]
```

</details>

## 10. LRU Cache — Medium

Design a cache of fixed capacity with `get(key)` and `put(key, value)` in $O(1)$; when full, evict the **least recently used** key.

<details>
<summary>Hint</summary>

Hash map for $O(1)$ lookup + doubly linked list for $O(1)$ "move to front" and "remove last". In Python, `OrderedDict` gives you both (`move_to_end`, `popitem(last=False)`). Interviewers often ask for the manual version too.

</details>

<details>
<summary>Implementation — OrderedDict</summary>

```python
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity):
        self.capacity = capacity
        self.data = OrderedDict()

    def get(self, key):
        if key not in self.data:
            return -1
        self.data.move_to_end(key)          # most recently used = end
        return self.data[key]

    def put(self, key, value):
        self.data[key] = value
        self.data.move_to_end(key)
        if len(self.data) > self.capacity:
            self.data.popitem(last=False)   # least recently used = front

c = LRUCache(2)
c.put(1, 1); c.put(2, 2)
assert c.get(1) == 1
c.put(3, 3)                 # evicts 2
assert c.get(2) == -1
c.put(4, 4)                 # evicts 1
assert c.get(1) == -1 and c.get(3) == 3 and c.get(4) == 4
```

</details>

<details>
<summary>Implementation — hash map + doubly linked list</summary>

```python
class Node:
    def __init__(self, key=0, val=0):
        self.key, self.val = key, val
        self.prev = self.next = None

class LRUCache:
    def __init__(self, capacity):
        self.capacity = capacity
        self.map = {}
        self.head, self.tail = Node(), Node()      # sentinels
        self.head.next, self.tail.prev = self.tail, self.head

    def _remove(self, node):
        node.prev.next, node.next.prev = node.next, node.prev

    def _add_front(self, node):
        node.prev, node.next = self.head, self.head.next
        self.head.next.prev = node
        self.head.next = node

    def get(self, key):
        if key not in self.map:
            return -1
        node = self.map[key]
        self._remove(node); self._add_front(node)
        return node.val

    def put(self, key, value):
        if key in self.map:
            self._remove(self.map[key])
        node = Node(key, value)
        self.map[key] = node
        self._add_front(node)
        if len(self.map) > self.capacity:
            lru = self.tail.prev
            self._remove(lru)
            del self.map[lru.key]

c = LRUCache(2)
c.put(1, 1); c.put(2, 2)
assert c.get(1) == 1
c.put(3, 3)
assert c.get(2) == -1
c.put(4, 4)
assert c.get(1) == -1 and c.get(3) == 3 and c.get(4) == 4
```

</details>

# Self-check

<details>
<summary>Why does a dummy head node simplify linked list code?</summary>

Without it, inserting at or deleting the head is a special case (the head pointer itself changes). With a dummy node before the head, every real node has a predecessor, so one code path handles all positions; return `dummy.next` at the end.

</details>
