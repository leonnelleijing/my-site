# Heaps & Priority Queues

A **binary heap** is a complete binary tree stored in an array where every parent is `<=` its children (**min-heap**). The smallest element is always at index 0.

```text
array:  [1, 3, 2, 7, 4, 5]          tree:        1
index:   0  1  2  3  4  5                      /   \
                                               3     2
children of i: 2i + 1, 2i + 2                 / \   /
parent of i:   (i - 1) // 2                  7   4 5
```

| Operation | Cost | How |
|---|---|---|
| peek min | $O(1)$ | `heap[0]` |
| push | $O(\log n)$ | add at the end, **sift up** while smaller than parent |
| pop min | $O(\log n)$ | move last to the root, **sift down** while bigger than a child |
| heapify a list | $O(n)$ | sift down from the middle to the start |

Python's `heapq` is a **min-heap**. For a max-heap, push `-x`. For objects, push tuples `(priority, tie_breaker, item)`.

```python
import heapq
h = []
heapq.heappush(h, 5); heapq.heappush(h, 1); heapq.heappush(h, 3)
heapq.heappop(h)            # 1
heapq.nsmallest(2, [5, 1, 3, 2])   # [1, 2]
```

<details>
<summary>Implementation — a min-heap from scratch</summary>

```python
class MinHeap:
    def __init__(self):
        self.a = []

    def push(self, x):
        a = self.a
        a.append(x)
        i = len(a) - 1
        while i > 0 and a[(i - 1) // 2] > a[i]:       # sift up
            p = (i - 1) // 2
            a[i], a[p] = a[p], a[i]
            i = p

    def pop(self):
        a = self.a
        top = a[0]
        last = a.pop()
        if a:
            a[0] = last
            i = 0
            while True:                               # sift down
                smallest, l, r = i, 2 * i + 1, 2 * i + 2
                if l < len(a) and a[l] < a[smallest]:
                    smallest = l
                if r < len(a) and a[r] < a[smallest]:
                    smallest = r
                if smallest == i:
                    break
                a[i], a[smallest] = a[smallest], a[i]
                i = smallest
        return top

    def __len__(self):
        return len(self.a)

h = MinHeap()
for x in [5, 3, 8, 1, 9, 2]:
    h.push(x)
assert [h.pop() for _ in range(len(h))] == [1, 2, 3, 5, 8, 9]
```

</details>

# The three heap patterns

| Pattern | Idea | Cost |
|---|---|---|
| **Top K** | keep a heap of size `k`; pop when it grows past `k` | $O(n \log k)$ |
| **K-way merge** | heap holds the current head of each of the `k` lists | $O(N \log k)$ |
| **Two heaps** | max-heap for the lower half, min-heap for the upper half | median in $O(1)$, insert $O(\log n)$ |

# Practice

## 1. Kth Largest Element in a Stream — Easy

Design a class that, after each `add(x)`, returns the `k`-th largest value seen so far.

<details>
<summary>Hint</summary>

Keep a **min-heap of size k**: it holds the k largest values, and its root is the k-th largest.

</details>

<details>
<summary>Implementation — O(log k) per add</summary>

```python
import heapq

class KthLargest:
    def __init__(self, k, nums):
        self.k = k
        self.heap = []
        for x in nums:
            self.add(x)

    def add(self, x):
        heapq.heappush(self.heap, x)
        if len(self.heap) > self.k:
            heapq.heappop(self.heap)          # drop the smallest
        return self.heap[0]

s = KthLargest(3, [4, 5, 8, 2])
assert [s.add(x) for x in [3, 5, 10, 9, 4]] == [4, 5, 5, 8, 8]
```

</details>

## 2. Top K Frequent Elements — Medium

```text
Input:  nums = [1, 1, 1, 2, 2, 3], k = 2
Output: [1, 2]
```

<details>
<summary>Hint</summary>

Count with `Counter`, then keep the k most frequent with a heap: `heapq.nlargest(k, counts, key=counts.get)`. Bonus $O(n)$: **bucket sort** where `bucket[f]` lists numbers with frequency `f`.

</details>

<details>
<summary>Implementation — heap O(n log k) and buckets O(n)</summary>

```python
import heapq
from collections import Counter

def top_k_frequent(nums, k):
    counts = Counter(nums)
    return heapq.nlargest(k, counts, key=counts.get)

def top_k_frequent_buckets(nums, k):
    counts = Counter(nums)
    buckets = [[] for _ in range(len(nums) + 1)]
    for x, f in counts.items():
        buckets[f].append(x)
    out = []
    for f in range(len(buckets) - 1, 0, -1):
        for x in buckets[f]:
            out.append(x)
            if len(out) == k:
                return out
    return out

assert top_k_frequent([1, 1, 1, 2, 2, 3], 2) == [1, 2]
assert top_k_frequent_buckets([1, 1, 1, 2, 2, 3], 2) == [1, 2]
assert top_k_frequent([1], 1) == [1]
```

</details>

## 3. K Closest Points to Origin — Medium

```text
Input:  points = [[3, 3], [5, -1], [-2, 4]], k = 2
Output: [[3, 3], [-2, 4]]
```

<details>
<summary>Hint</summary>

Top K with a **max-heap** of size k on distance (push `-distance`). No need for `sqrt`: comparing $x^2 + y^2$ gives the same order.

</details>

<details>
<summary>Implementation — O(n log k)</summary>

```python
import heapq

def k_closest(points, k):
    heap = []                                 # (-dist², x, y): max-heap
    for x, y in points:
        heapq.heappush(heap, (-(x * x + y * y), x, y))
        if len(heap) > k:
            heapq.heappop(heap)               # remove the farthest
    return sorted([[x, y] for _, x, y in heap], key=lambda p: p[0] ** 2 + p[1] ** 2)

assert k_closest([[3, 3], [5, -1], [-2, 4]], 2) == [[3, 3], [-2, 4]]
assert k_closest([[1, 3], [-2, 2]], 1) == [[-2, 2]]
```

</details>

## 4. Merge K Sorted Lists — Hard

Merge `k` sorted lists into one sorted list.

```text
Input:  [[1, 4, 5], [1, 3, 4], [2, 6]]
Output: [1, 1, 2, 3, 4, 4, 5, 6]
```

<details>
<summary>Hint</summary>

Push the first element of each list as `(value, list_index, element_index)`. Pop the smallest, append it, push the next element from the same list.

</details>

<details>
<summary>Implementation — O(N log k)</summary>

```python
import heapq

def merge_k_sorted(lists):
    heap = [(lst[0], i, 0) for i, lst in enumerate(lists) if lst]
    heapq.heapify(heap)
    out = []
    while heap:
        val, i, j = heapq.heappop(heap)
        out.append(val)
        if j + 1 < len(lists[i]):
            heapq.heappush(heap, (lists[i][j + 1], i, j + 1))
    return out

assert merge_k_sorted([[1, 4, 5], [1, 3, 4], [2, 6]]) == [1, 1, 2, 3, 4, 4, 5, 6]
assert merge_k_sorted([[], [1]]) == [1]
assert merge_k_sorted([]) == []
```

</details>

## 5. Find Median from Data Stream — Hard

Support `add_num(x)` and `find_median()` efficiently.

<details>
<summary>Hint</summary>

Two heaps: `low` is a max-heap with the smaller half, `high` a min-heap with the larger half. Keep `len(low) == len(high)` or one more in `low`. The median is the top of `low`, or the average of both tops.

</details>

<details>
<summary>Implementation — O(log n) add, O(1) median</summary>

```python
import heapq

class MedianFinder:
    def __init__(self):
        self.low = []      # max-heap (stored negated)
        self.high = []     # min-heap

    def add_num(self, x):
        heapq.heappush(self.low, -x)
        heapq.heappush(self.high, -heapq.heappop(self.low))   # move the max of low up
        if len(self.high) > len(self.low):
            heapq.heappush(self.low, -heapq.heappop(self.high))

    def find_median(self):
        if len(self.low) > len(self.high):
            return float(-self.low[0])
        return (-self.low[0] + self.high[0]) / 2

m = MedianFinder()
m.add_num(1); m.add_num(2)
assert m.find_median() == 1.5
m.add_num(3)
assert m.find_median() == 2.0
```

</details>

## 6. Task Scheduler — Medium

CPU tasks (letters), each takes one unit; the same task needs `n` idle units between two runs. Minimum total time?

```text
Input:  tasks = ["A","A","A","B","B","B"], n = 2
Output: 8          A B _ A B _ A B
```

<details>
<summary>Hint</summary>

Greedy formula: the most frequent task (count `f_max`) forms `f_max - 1` blocks of length `n + 1`, plus one final slot per task tied for the max count. The answer is `max(len(tasks), (f_max - 1) * (n + 1) + ties)`.

</details>

<details>
<summary>Implementation — O(n)</summary>

```python
from collections import Counter

def least_interval(tasks, n):
    counts = Counter(tasks).values()
    f_max = max(counts)
    ties = sum(1 for c in counts if c == f_max)
    return max(len(tasks), (f_max - 1) * (n + 1) + ties)

assert least_interval(["A", "A", "A", "B", "B", "B"], 2) == 8
assert least_interval(["A", "A", "A", "B", "B", "B"], 0) == 6
assert least_interval(["A", "A", "A", "A", "A", "A", "B", "C", "D", "E", "F", "G"], 2) == 16
```

</details>

# Self-check

<details>
<summary>Why is building a heap from a list O(n) and not O(n log n)?</summary>

Sifting down costs the height of the node, and most nodes are near the bottom: half the nodes have height 0, a quarter height 1, and so on. The sum $\sum_h \frac{n}{2^{h+1}} \cdot h$ is $O(n)$.

</details>

<details>
<summary>For "top k largest", why use a min-heap rather than a max-heap?</summary>

A min-heap of size k keeps the k largest so far, and its root is the weakest of them: any new element bigger than the root replaces it. Memory is $O(k)$ and time $O(n \log k)$, instead of $O(n)$ memory for a max-heap of everything.

</details>
