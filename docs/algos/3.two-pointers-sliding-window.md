# Two Pointers & Sliding Window

Both patterns replace a nested $O(n^2)$ loop with **one pass** of two indices that only move forward: $O(n)$.

| Pattern | Pointers | Typical problem |
|---|---|---|
| **Opposite ends** | `l = 0`, `r = n - 1`, move toward each other | pair sum in a sorted array, palindrome, container |
| **Fast / slow** | both start left, one moves faster | remove duplicates in place, cycle detection |
| **Sliding window** | `[l, r]` grows on the right, shrinks on the left | longest / shortest substring with a property |
| **Prefix sums** | `prefix[i]` = sum of the first `i` items | sum of any range in $O(1)$ |

# Opposite ends

```text
sorted: [1  2  4  7  11  15],  target = 15
         l                r     1 + 15 = 16 > 15 → r--
         l             r        1 + 11 = 12 < 15 → l++
            l          r        2 + 11 = 13 < 15 → l++
               l       r        4 + 11 = 15  found
```

Because the array is sorted, moving `r` left can only decrease the sum and moving `l` right can only increase it, so no pair is skipped.

<details>
<summary>Implementation — pair with target sum (sorted input)</summary>

```python
def two_sum_sorted(nums, target):
    l, r = 0, len(nums) - 1
    while l < r:
        s = nums[l] + nums[r]
        if s == target:
            return [l, r]
        if s < target:
            l += 1
        else:
            r -= 1
    return []

assert two_sum_sorted([1, 2, 4, 7, 11, 15], 15) == [2, 4]
assert two_sum_sorted([1, 2], 5) == []
```

</details>

# Sliding window

Keep a window `[l, r]`. Extend `r` each step; while the window breaks the rule, shrink from `l`. Each index enters and leaves the window once: $O(n)$.

```text
longest substring without repeating characters: "abcabcbb"
[a]bcabcbb        len 1
[abc]abcbb        len 3
a[bca]bcbb        'a' repeated → move l past the first 'a'
...               best = 3
```

<details>
<summary>Implementation — variable window template (longest substring with at most k distinct characters)</summary>

```python
from collections import Counter

def longest_k_distinct(s, k):
    count = Counter()                 # window state
    best = l = 0
    for r, ch in enumerate(s):
        count[ch] += 1                # 1. grow the window on the right
        while len(count) > k:         # 2. shrink from the left while invalid
            count[s[l]] -= 1
            if count[s[l]] == 0:
                del count[s[l]]
            l += 1
        best = max(best, r - l + 1)   # 3. window [l, r] is valid: record it
    return best

def longest_two_distinct(s):
    return longest_k_distinct(s, 2)

assert longest_two_distinct("eceba") == 3      # "ece"
assert longest_two_distinct("ccaabbb") == 5    # "aabbb"
```

</details>

# Prefix sums

$$
\text{prefix}[i] = \sum_{k=0}^{i-1} a_k \qquad \text{sum}(l..r) = \text{prefix}[r+1] - \text{prefix}[l]
$$

Combined with a hash map of prefix sums seen so far, it counts subarrays with a given sum, even with negative numbers (where a sliding window doesn't work).

# Practice

## 1. Valid Palindrome — Easy

Is the string a palindrome, considering only letters and digits and ignoring case?

```text
Input:  "A man, a plan, a canal: Panama"
Output: True
```

<details>
<summary>Hint</summary>

Pointers at both ends; skip characters that aren't alphanumeric; compare lowercase versions.

</details>

<details>
<summary>Implementation — O(n) time, O(1) space</summary>

```python
def is_palindrome(s):
    l, r = 0, len(s) - 1
    while l < r:
        if not s[l].isalnum():
            l += 1
        elif not s[r].isalnum():
            r -= 1
        elif s[l].lower() != s[r].lower():
            return False
        else:
            l += 1; r -= 1
    return True

assert is_palindrome("A man, a plan, a canal: Panama")
assert not is_palindrome("race a car")
assert is_palindrome(" ")
```

</details>

## 2. Container With Most Water — Medium

`height[i]` is a vertical line. Choose two lines that, with the x-axis, hold the most water.

```text
Input:  [1, 8, 6, 2, 5, 4, 8, 3, 7]
Output: 49        (lines at index 1 and 8: min(8, 7) * 7)
```

<details>
<summary>Hint</summary>

Start with the widest container. The area is limited by the **shorter** line, so moving the taller one inward can never help: always move the shorter one.

</details>

<details>
<summary>Implementation — O(n)</summary>

```python
def max_area(height):
    l, r, best = 0, len(height) - 1, 0
    while l < r:
        best = max(best, min(height[l], height[r]) * (r - l))
        if height[l] < height[r]:
            l += 1
        else:
            r -= 1
    return best

assert max_area([1, 8, 6, 2, 5, 4, 8, 3, 7]) == 49
assert max_area([1, 1]) == 1
```

</details>

## 3. 3Sum — Medium

Return all **unique** triplets that sum to 0.

```text
Input:  [-1, 0, 1, 2, -1, -4]
Output: [[-1, -1, 2], [-1, 0, 1]]
```

<details>
<summary>Hint</summary>

Sort. Fix the first number `nums[i]`, then run two-pointer pair search on the rest for `-nums[i]`. Skip equal neighbours to avoid duplicate triplets. $O(n^2)$.

</details>

<details>
<summary>Implementation — O(n²)</summary>

```python
def three_sum(nums):
    nums.sort()
    res = []
    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue                       # same first number → same triplets
        if nums[i] > 0:
            break                          # sorted: no way to reach 0
        l, r = i + 1, len(nums) - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if s < 0:
                l += 1
            elif s > 0:
                r -= 1
            else:
                res.append([nums[i], nums[l], nums[r]])
                l += 1; r -= 1
                while l < r and nums[l] == nums[l - 1]:
                    l += 1
    return res

assert three_sum([-1, 0, 1, 2, -1, -4]) == [[-1, -1, 2], [-1, 0, 1]]
assert three_sum([0, 0, 0, 0]) == [[0, 0, 0]]
assert three_sum([0, 1, 1]) == []
```

</details>

## 4. Longest Substring Without Repeating Characters — Medium

```text
Input:  "abcabcbb"
Output: 3          ("abc")
```

<details>
<summary>Hint</summary>

Sliding window plus a map `char → last index`. When you see a repeated char inside the window, jump `l` to just after its previous position.

</details>

<details>
<summary>Implementation — O(n)</summary>

```python
def length_of_longest_substring(s):
    last = {}
    best = l = 0
    for r, ch in enumerate(s):
        if ch in last and last[ch] >= l:
            l = last[ch] + 1
        last[ch] = r
        best = max(best, r - l + 1)
    return best

assert length_of_longest_substring("abcabcbb") == 3
assert length_of_longest_substring("bbbbb") == 1
assert length_of_longest_substring("pwwkew") == 3
assert length_of_longest_substring("") == 0
```

</details>

## 5. Minimum Window Substring — Hard

Smallest substring of `s` containing every character of `t` (with multiplicity).

```text
Input:  s = "ADOBECODEBANC", t = "ABC"
Output: "BANC"
```

<details>
<summary>Hint</summary>

Count what `t` needs. Grow `r` until the window has everything (`missing == 0`), then shrink `l` as far as it stays valid, recording the best window.

</details>

<details>
<summary>Implementation — O(|s| + |t|)</summary>

```python
from collections import Counter

def min_window(s, t):
    need = Counter(t)
    missing = len(t)
    best = (0, float("inf"))
    l = 0
    for r, ch in enumerate(s):
        if need[ch] > 0:
            missing -= 1
        need[ch] -= 1
        while missing == 0:                  # window is valid: try to shrink
            if r - l < best[1] - best[0]:
                best = (l, r)
            need[s[l]] += 1
            if need[s[l]] > 0:
                missing += 1
            l += 1
    return "" if best[1] == float("inf") else s[best[0]:best[1] + 1]

assert min_window("ADOBECODEBANC", "ABC") == "BANC"
assert min_window("a", "aa") == ""
assert min_window("a", "a") == "a"
```

</details>

## 6. Subarray Sum Equals K — Medium

Count contiguous subarrays whose sum is `k` (numbers can be negative).

```text
Input:  nums = [1, 2, 3], k = 3
Output: 2          ([1, 2] and [3])
```

<details>
<summary>Hint</summary>

A subarray ending at `r` sums to `k` when `prefix[r] - prefix[l] = k`, i.e. `prefix[l] = prefix[r] - k`. Count how many times each prefix sum has been seen.

</details>

<details>
<summary>Implementation — O(n)</summary>

```python
from collections import defaultdict

def subarray_sum(nums, k):
    seen = defaultdict(int)
    seen[0] = 1                  # empty prefix
    total = count = 0
    for x in nums:
        total += x
        count += seen[total - k]
        seen[total] += 1
    return count

assert subarray_sum([1, 2, 3], 3) == 2
assert subarray_sum([1, 1, 1], 2) == 2
assert subarray_sum([1, -1, 0], 0) == 3
```

</details>

# Self-check

<details>
<summary>Why doesn't a sliding window work for "subarray sum = k" with negative numbers?</summary>

The window relies on monotonicity: adding an element should only increase the sum and removing one only decrease it. With negatives, shrinking can increase the sum, so you can't know which way to move. Prefix sums + hash map work for any numbers.

</details>
