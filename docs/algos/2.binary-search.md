# Binary Search

Search a **sorted** (or "monotonic") space by checking the middle and throwing away the half that can't contain the answer. Each step halves the space: $O(\log n)$.

```text
target = 23
[2  5  8  12  16  23  38  56  72  91]
 L              M                  R    16 < 23 → go right
                    L      M       R    56 > 23 → go left
                    L  M R              23 found
```

The hard part is **off-by-one errors**. Pick one template and always use it.

| Template | Loop | Use when |
|---|---|---|
| exact match | `while lo <= hi` | find an index of `target` |
| **lower bound** | `while lo < hi` | first index where a condition becomes true |

<details>
<summary>Implementation — exact match</summary>

```python
def binary_search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2         # in Java/C++: lo + (hi - lo) / 2 avoids overflow
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1

nums = [2, 5, 8, 12, 16, 23, 38, 56, 72, 91]
assert binary_search(nums, 23) == 5
assert binary_search(nums, 7) == -1
assert binary_search([], 1) == -1
```

</details>

<details>
<summary>Implementation — lower bound (first index where condition is true)</summary>

```python
def first_true(lo, hi, condition):
    """Smallest x in [lo, hi] with condition(x) True.
    condition must be False...False True...True. Returns hi + 1 if none."""
    hi += 1
    while lo < hi:
        mid = (lo + hi) // 2
        if condition(mid):
            hi = mid                 # mid may be the answer, keep it
        else:
            lo = mid + 1
    return lo

nums = [1, 3, 3, 3, 7, 9]
# first index with nums[i] >= 3  (same as bisect.bisect_left)
assert first_true(0, len(nums) - 1, lambda i: nums[i] >= 3) == 1
# first index with nums[i] > 3   (same as bisect.bisect_right)
assert first_true(0, len(nums) - 1, lambda i: nums[i] > 3) == 4
```

</details>

Python already has it: `bisect.bisect_left(a, x)` and `bisect.bisect_right(a, x)`.

# Binary search on the answer

Many problems don't look like searching an array: *"find the minimum speed / capacity / time such that X is possible"*. If being feasible is **monotonic** (once it works with value `v`, it also works for everything bigger), binary search over the **values**:

```text
speed:     1  2  3  4  5  6  7 ...
feasible:  F  F  F  T  T  T  T      → answer = first T
```

Complexity: $O(\log(\text{range}) \times \text{cost of one check})$.

# Practice

## 1. Search in Rotated Sorted Array — Medium

A sorted array of distinct numbers was rotated at an unknown pivot. Find `target` in $O(\log n)$.

```text
Input:  nums = [4, 5, 6, 7, 0, 1, 2], target = 0
Output: 4
```

<details>
<summary>Hint</summary>

At any `mid`, **one half is always sorted**. Check if `target` lies inside the sorted half's range; if yes go there, otherwise go to the other half.

</details>

<details>
<summary>Implementation — O(log n)</summary>

```python
def search_rotated(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        if nums[lo] <= nums[mid]:                 # left half sorted
            if nums[lo] <= target < nums[mid]:
                hi = mid - 1
            else:
                lo = mid + 1
        else:                                     # right half sorted
            if nums[mid] < target <= nums[hi]:
                lo = mid + 1
            else:
                hi = mid - 1
    return -1

assert search_rotated([4, 5, 6, 7, 0, 1, 2], 0) == 4
assert search_rotated([4, 5, 6, 7, 0, 1, 2], 3) == -1
assert search_rotated([1], 1) == 0
```

</details>

## 2. First and Last Position — Medium

Return the first and last index of `target` in a sorted array with duplicates, or `[-1, -1]`.

```text
Input:  nums = [5, 7, 7, 8, 8, 10], target = 8
Output: [3, 4]
```

<details>
<summary>Hint</summary>

Two lower-bound searches: first index with `x >= target`, and first index with `x > target` (minus one).

</details>

<details>
<summary>Implementation — O(log n)</summary>

```python
from bisect import bisect_left, bisect_right

def search_range(nums, target):
    left = bisect_left(nums, target)
    if left == len(nums) or nums[left] != target:
        return [-1, -1]
    return [left, bisect_right(nums, target) - 1]

assert search_range([5, 7, 7, 8, 8, 10], 8) == [3, 4]
assert search_range([5, 7, 7, 8, 8, 10], 6) == [-1, -1]
assert search_range([], 0) == [-1, -1]
```

</details>

## 3. Koko Eating Bananas — Medium

`piles[i]` bananas in each pile, `h` hours. Each hour Koko eats up to `k` bananas from one pile. Find the **minimum** `k` that finishes all piles within `h` hours.

```text
Input:  piles = [3, 6, 7, 11], h = 8
Output: 4
```

<details>
<summary>Hint</summary>

Binary search on the answer `k` in `[1, max(piles)]`. Hours needed for speed `k` is `sum(ceil(p / k))`, which only decreases as `k` grows: monotonic.

</details>

<details>
<summary>Implementation — O(n log max)</summary>

```python
def min_eating_speed(piles, h):
    def hours(k):
        return sum((p + k - 1) // k for p in piles)   # ceil without floats

    lo, hi = 1, max(piles)
    while lo < hi:
        mid = (lo + hi) // 2
        if hours(mid) <= h:
            hi = mid
        else:
            lo = mid + 1
    return lo

assert min_eating_speed([3, 6, 7, 11], 8) == 4
assert min_eating_speed([30, 11, 23, 4, 20], 5) == 30
assert min_eating_speed([30, 11, 23, 4, 20], 6) == 23
```

</details>

## 4. Median of Two Sorted Arrays — Hard

Find the median of two sorted arrays in $O(\log(\min(m, n)))$.

```text
Input:  a = [1, 3], b = [2]
Output: 2.0
```

<details>
<summary>Hint</summary>

Binary search a **cut** in the smaller array. If `i` elements come from `a`, then `half - i` come from `b`. The cut is right when everything on the left side is `<=` everything on the right: `a[i-1] <= b[j]` and `b[j-1] <= a[i]`.

</details>

<details>
<summary>Implementation — O(log min(m, n))</summary>

```python
def find_median(a, b):
    if len(a) > len(b):
        a, b = b, a
    m, n = len(a), len(b)
    half = (m + n + 1) // 2
    lo, hi = 0, m
    while lo <= hi:
        i = (lo + hi) // 2
        j = half - i
        a_left = a[i - 1] if i > 0 else float("-inf")
        a_right = a[i] if i < m else float("inf")
        b_left = b[j - 1] if j > 0 else float("-inf")
        b_right = b[j] if j < n else float("inf")
        if a_left <= b_right and b_left <= a_right:
            if (m + n) % 2:
                return float(max(a_left, b_left))
            return (max(a_left, b_left) + min(a_right, b_right)) / 2
        if a_left > b_right:
            hi = i - 1
        else:
            lo = i + 1

assert find_median([1, 3], [2]) == 2.0
assert find_median([1, 2], [3, 4]) == 2.5
assert find_median([], [1]) == 1.0
```

</details>

# Self-check

<details>
<summary>Why do we write lo + (hi - lo) / 2 in Java?</summary>

`lo + hi` can overflow a 32-bit `int` when both are large; `lo + (hi - lo) / 2` gives the same value without overflow. Python integers don't overflow.

</details>

<details>
<summary>How do you know binary search on the answer applies?</summary>

Write a function `feasible(x)` and check it is monotonic: if `feasible(x)` is true, then `feasible(x + 1)` is also true (or the reverse). Then the answers look like `F F F T T T` and you search for the first `T`.

</details>
