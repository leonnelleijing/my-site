# My Blog — Docusaurus website

This repository contains a Docusaurus-based static website that hosts the blog and documentation.

Quick links:

- `docs/README.md` — Documentation: structure and how to add docs.
- `blog/README.md` — Blog: how to add and format posts.
- `src/README.md` — Frontend: component and pages layout, development notes.
- `CONTRIBUTING.md` — Contribution, build and deployment instructions.

Quick start

```bash
yarn
yarn start
```

- `yarn start` starts a local development server and opens a browser. Changes are reflected live.
- `yarn build` generates static files into the `build` directory.

If you're contributing or deploying the site, see `CONTRIBUTING.md` for details.
